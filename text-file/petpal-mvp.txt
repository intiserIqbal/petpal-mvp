# PetPal: AI-Enhanced Pet Adoption Platform

## 🎯 Project Overview
**PetPal** is a cross-platform pet adoption app that uses real AI APIs for sentiment analysis. Built with React Native + Expo for iOS, Android, and Web deployment.

---

## 🚀 Quick Facts
- **Timeline**: 15 days
- **Team**: 2 people (Frontend + Backend)
- **Platforms**: iOS, Android, Web
- **Tech Stack**: 100% Free Tier
- **Key Feature**: Hugging Face AI API integration

## 🔌 API Integration Details

### **Hugging Face Sentiment Analysis**
```javascript
// Backend route - /api/analyze-sentiment
app.post('/api/analyze-sentiment', async (req, res) => {
  const { text } = req.body;
  
  const response = await fetch(
    'https://api-inference.huggingface.co/models/distilbert-base-uncased-finetuned-sst-2-english',
    {
      headers: { Authorization: `Bearer ${process.env.HUGGINGFACE_TOKEN}` },
      method: 'POST',
      body: JSON.stringify({ inputs: text }),
    }
  );
  
  const result = await response.json();
  res.json(result); // Returns: [[{label: 'POSITIVE', score: 0.99}]]
});
```

### **Frontend Usage**
- Analyze pet descriptions during creation
- Display sentiment badges on pet cards
- Moderate reviews automatically
